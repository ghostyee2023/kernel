# Kernel · 创意种子 — 实施路线图与成本估算

---

## 一、分期规划

### P0 · 骨架跑通（2 周）
> 目标：能上传、能出链接、能访问、能过期

| 项 | 交付 |
|----|------|
| 基建 | Next.js + Prisma + Postgres + Redis + Docker Compose 起环境 |
| 上传 | 单文件 / ZIP 上传，安全校验流水线，落盘 |
| 短码 | Base58 生成 + 唯一约束 + 目录映射 |
| 沙箱 | Nginx 泛域名 + 安全响应头 + 证书 |
| 生命周期 | expireAt 字段 + 每日归档任务 + 回收站 |
| 页面 | 上传页、发布成功页、作品详情页（无投票） |

**验收**：传一个 zip，拿到 `k7Rm2xQz.demo-sandbox.com`，浏览器能正常打开，90 天后自动下线。

---

### P1 · 社区闭环（2–3 周）
> 目标：能登录、能投票、能上榜

| 项 | 交付 |
|----|------|
| 登录 | 微信扫码 + 微信内授权 + unionid 打通 |
| 投票 | 投票 API（幂等 + 限流 + Redis 计数）、乐观 UI |
| 活动 | Campaign CRUD、作品报名、投票规则配置 |
| 排行榜 | Redis ZSET 实时榜 + 热度算法 + 榜单页 |
| 广场 | 作品列表、筛选、排序、搜索 |
| 可见性 | 公开 / 仅链接 / 私密三态 + 私密签名访问 |

**验收**：办一场真实活动，20 件作品、100 人投票，榜单实时准确。

---

### P2 · 运营与治理（2 周）
> 目标：管理员能管、能查、能防

| 项 | 交付 |
|----|------|
| 后台 | 概览、作品管理、活动管理、用户管理 |
| 风控 | 设备指纹、风险评分、可疑票聚合、批量作废 + 榜单重算 |

**验收**：模拟一次刷票攻击，后台能定位到来源并一键作废。

---

### P3 · 体验打磨（1–2 周）
> 目标：好看、好分享、好传播

|----|------|

| 封面 | Playwright 自动截图 |

### P4 · 可选增强（按需）
自定义域名绑定 · 版本管理与回滚 · 评委打分制（多维评分而非单一点赞） · 作品评论 · 团队空间 · 数据导出 API · 内容安全自动扫描（ClamAV / 内容审核 API）

## 二、人力与周期

| 角色 | 投入 | 说明 |
|------|------|------|
| 全栈开发 | 1 人 × 8 周 | P0–P3 主力 |
| 前端/设计 | 0.5 人 × 4 周 | 设计规范落地 + 页面打磨 |
| 运维 | 0.2 人 × 全程 | 域名、证书、部署、监控 |

**单人全栈**可行，总周期约 **7–9 周**；两人并行可压缩到 **5 周**。

## 三、成本估算（年）

### 自建方案（推荐起步）

| 项 | 规格 | 年成本（人民币，估） |
|----|------|------|
| 云服务器 | 4C8G + 100GB SSD | ¥3,000–4,500 |
| 对象存储 | 100GB + 流量 | ¥600–1,200 |
| CDN | 500GB/月 | ¥1,200–2,400 |
| 域名 | 主域 + 沙箱域 | ¥120 |
| 泛域名证书 | Let's Encrypt | ¥0 |
| 微信开放平台 | 网站应用认证 | ¥300/年 |
| **合计** | | **约 ¥5,200–8,500 / 年** |

### Serverless 方案（流量小时更省）
Vercel/Netlify（主站）+ Supabase（DB+Auth）+ Cloudflare R2（存储）+ Cloudflare Workers（沙箱路由）
起步近乎免费，但**国内访问速度与微信登录合规性需实测**，且沙箱隔离控制力弱一档。

> **建议**：面向国内活动场景 → 自建 + 国内云；面向海外/内部小团队 → Serverless。

## 四、风险清单与应对

| 风险 | 等级 | 应对 |
|------|:---:|------|
| 沙箱隔离没做好导致 XSS 打穿主站 | 🔴 高 | **必须**独立注册域名 + 无 cookie + CSP + iframe 不给 same-origin。上线前做一次渗透自测 |
| 用户上传违规内容 | 🔴 高 | 举报入口 + 管理员一键下架 + 保留 IP 日志 + 用户协议 + 必要时接内容审核 API |
| 备案与域名合规 | 🟡 中 | 沙箱域名同样需备案；提前 20 天准备 |
| 刷票导致活动公信力受损 | 🟡 中 | 六层防护 + 结果公示前人工复核 + 支持"截止后公布"模式 |
| 存储成本失控 | 🟡 中 | 默认 90 天回收 + 单项目 200MB 配额 + 用量告警 |
| 微信登录资质 | 🟡 中 | 需企业主体 + 开放平台认证（300 元/年）；准备手机号登录兜底 |
| Playwright 截图内存泄漏 | 🟢 低 | 独立 worker 容器 + 单任务超时 30s + 定期重启 |

## 五、上线检查清单

**安全**
- [ ] 沙箱域名与主域名是**不同注册域**
- [ ] 沙箱域下 `Set-Cookie` 为空（curl 验证）
- [ ] CSP `form-action 'none'` 已生效
- [ ] iframe 未包含 `allow-same-origin`
- [ ] ZIP 炸弹 / 路径穿越用测试样本验证通过
- [ ] 私密作品未登录访问返回 404 而非 403（不泄露存在性）

**功能**
- [ ] 90 天默认有效期正确写入且归档任务跑通
- [ ] 投票幂等：重复点击不重复计票
- [ ] 微信 unionid 在公众号与扫码两条链路上一致
- [ ] 管理员可见私密作品且写入审计日志
- [ ] 榜单在票作废后能正确重算

**体验**
- [ ] 375px 宽度下所有页面无横向滚动
- [ ] 主 CTA 触摸目标 ≥ 44px
- [ ] 首页 LCP < 1.5s
- [ ] 暗色主题无硬编码色值残留
- [ ] 空状态、加载态、错误态全部有设计

**运维**
- [ ] 数据库每日备份且做过一次恢复演练
- [ ] 磁盘 80% 告警已接入
- [ ] Sentry 已上报且 SourceMap 可读
